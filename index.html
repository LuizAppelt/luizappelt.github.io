// 01 — sobre mim

Quem sou eu

Full-stack QA Back-end Front-end

Olá! Sou Luiz Appelt, graduando em Ciência da Computação na Universidade ATITUS (Campus Passo Fundo/RS), com previsão de formação em 2029.

Tenho sólida base em lógica de programação, estruturas de dados (listas encadeadas, filas e pilhas), programação orientada a objetos (POO) e qualidade de software. Na prática, desenvolvo aplicações modernas unindo TypeScript, React 19, Python e Java com persistência em bancos de dados (PostgreSQL/Supabase) e consumo de APIs REST.

Possuo vivência profissional em suporte a sistemas ERP, controle de dados e garantia de conformidade técnica. Busco oportunidades de Estágio / Júnior para somar na entrega de soluções escaláveis, organizadas e com alto rigor de qualidade.
